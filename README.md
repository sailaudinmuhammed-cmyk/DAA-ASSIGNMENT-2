DAA Assignment 2

This project is for Assignment 2 of the Design and Analysis of Algorithms course.

The project implements and compares three data structures:

- Dynamic Array
- Linked List
- Min Heap

The program includes basic operations for each data structure, correctness testing, and performance benchmarks.

Implemented Operations

Dynamic Array
- add
- add by index
- remove
- get
- contains

Linked List
- add
- add by index
- remove
- get
- contains

Min Heap
- insert
- peekMin
- extractMin

Benchmark

The benchmark compares the data structures using different input sizes:

- 100
- 1,000
- 10,000
- 100,000

The experiments include:

- Random access
- Search
- Insertion and removal
- Min Heap insertion and extraction

Execution time is measured using `System.nanoTime()`.

Benchmark results are saved in the `results/tables` folder.
